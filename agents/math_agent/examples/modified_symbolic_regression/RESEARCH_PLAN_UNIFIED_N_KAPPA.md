# 基于 modified_symbolic_regression 的跨电子数与跨 κ 统一波函数研究方案

日期：2026-10-01。本文根据当前仓库实现、已有数据检查和相关物理文献编写；文中的候选公式、精度阈值和实验安排是研究设计，尚不是已取得的实验结果。

## 1. 研究目标与范围

建议采用“先识别物理态及其分支，再发现共享解析结构，最后验证未见条件”的路线。保留当前 LoongFlow 的 PES 演化搜索、多岛初始化、受限 AST 求值与精度—复杂度 Pareto 选择，扩展任务层的数据接口、表达式语法和联合评估。

两项实验分别回答：

| 实验 | 固定条件 | 变化条件 | 预期交付 |
| --- | --- | --- | --- |
| A：跨电子数 | κ = 100，ν = 1/3，d/l_B = 0.1 | N = 2、3、4、5、6 | 可输入可变长度电子坐标、具有共享结构和参数规律的 Ψ_N |
| B：跨 κ | N = N₀，ν = 1/3，d/l_B = 0.1 | κ ∈ [1, 100] | 显式包含 κ、可在未见 κ 上预测的 Ψ_{N₀}(κ) |

**工作假设**：原始列表“(2,34,5,6)”暂解释为“(2,3,4,5,6)”；实验 B 的固定电子数尚未指定，建议 N₀ = 4 为主实验、N₀ = 2 为流程验证。如果列表实际包含 N = 34，按第 11 节的扩展路线处理。如果实验 B 改为 N₀ = 2 或 6，保留同样的设计，只调整数据规模和计算预算。

“统一”分三个层次，报告中必须区分：

1. **结构统一**：不同 N 或 κ 使用同一种公式结构，但每个条件分别拟合参数。这是发现规律的中间步骤。
2. **参数规律统一**：使用固定数量的共享系数，以及显式的 N、κ 依赖；新条件只输入 N 或 κ，不重新拟合形状参数。这是两项主实验的目标。
3. **适用范围得到验证**：通过留出整个电子数或整个 κ 的测试，并在新增条件上验证。有限个小体系上的成功不能证明任意 N 的基态都已被精确描述。

最终表达可对一般 N ≥ 2 定义，但科学结论应写成“在已测试范围内成立的可扩展试探态”。N = 1 的形式退化与归一化可单独定义。波函数整体归一化和全局相位不计入形状参数。

多岛初始化兼容逻辑已出现在当前 `math_evolve_agent.py` 和 `pes_agent.py` 中，因此无需重复应用 README 中的补丁；后续应验证六个新种子确实分别进入对应的岛。

## 3. 物理模型与约束

### 3.1 固定无量纲问题，避免同时改变多个物理条件

沿用当前模型：二维、完全自旋极化电子，垂直磁场、电子间库仑作用，距离电子平面 d = 0.1 l_B 的均匀正电荷圆盘。正电荷为 +Ne，填充参数 ν = 1/3，长度单位为磁长度 l_B。

定义

$$
\kappa = \frac{E_C}{\hbar\omega_c},\qquad
E_C = \frac{e^2}{4\pi\epsilon_0\epsilon_r l_B},\qquad
a_N/l_B = \sqrt{6N},\qquad Q = \Phi/\Phi_0 = 3N.
$$

这里 Q 是圆盘背景区域内的磁通数，不是球面几何的通量量子数；不要套用球面 shift 修正。

取无量纲坐标 **r** = **r**_phys/l_B，电子电荷为 −e，磁场沿 +z，采用对称规范。研究中应先核对原始数据生成器的规范及符号；标准形式为

$$
\frac{H}{\hbar\omega_c}
= \frac12\sum_i\left[-i\nabla_i+\frac12\hat{\mathbf z}\times\mathbf r_i\right]^2
+\kappa\left[\sum_{i<j}\frac1{r_{ij}}+\sum_i v_{\mathrm{eb}}(\mathbf r_i;N)+v_{\mathrm{bb}}(N)\right],
$$

其中

$$
v_{\mathrm{eb}}(\mathbf r;N)
=-\frac{N}{\pi a_N^2}\int_{|\mathbf R|\le a_N}
\frac{d^2\mathbf R}{\sqrt{|\mathbf r-\mathbf R|^2+(1/10)^2}}.
$$

式中 a_N 已取无量纲值；背景自能 v_bb 对波函数不产生作用，但报告不同条件的总能量时应统一计入。若改用 E_C 作为能量单位，则动能系数变为 1/κ，物理问题等价。

实验 A 改变 N 时必须同步改变圆盘半径和背景总电荷，保持背景面密度不变。实验 B 改变 κ 时保持 a_N/l_B、d/l_B 和 ν 不变。若通过实验磁场 B 实现 κ 扫描，则物理长度、背景密度及 d 都需要相应缩放；固定真实长度扫描 B 是另一项多参数实验。

### 3.2 κ = 100 时允许非全纯结构

κ = 100 不能作为小参数处理，也不能预设目标属于最低 Landau 能级（LLL）。允许 |z|、共轭坐标、径向相关与回流结构。微扰 LLL 有效哈密顿量适合作为弱混合参照，不适合作为 κ = 100 的默认描述。[Sodemann 与 MacDonald，Landau Level Mixing and the Fractional Quantum Hall Effect](https://arxiv.org/abs/1302.3896)

强 Landau 能级混合可能增强晶体关联，但有限圆盘上的具体态必须由数据诊断。已有圆盘实空间神经网络研究报告了非全纯短程结构、强混合下角动量变化与旋转晶体关联，这为分支诊断提供动机，不能直接替代本项目的测量。[Teng、Dai 与 Fu，Solving and visualizing fractional quantum Hall wavefunctions with neural network](https://arxiv.org/abs/2412.00618)

### 3.3 交换反对称性与角动量必须由构造保证

沿用当前坐标约定：

$$
z_i=x_i-i y_i,\qquad
\Psi(\ldots,z_i,\ldots,z_j,\ldots)=-\Psi(\ldots,z_j,\ldots,z_i,\ldots),
$$

$$
\Psi(\{e^{-i\phi}z_i\})=e^{-iM\phi}\Psi(\{z_i\}),\qquad M\in\mathbb Z.
$$

本文 M 是上述旋转变换中的整数标签。若使用通常的算子 `L_z = -iℏ(x∂_y − y∂_x)`，其本征值对应 −Mℏ；与数据生成器比较时必须先对齐这一符号，不能只比较数值绝对值。

圆盘背景选定了空间原点，所以不应强制平移不变或假定质心与相对坐标严格分离。应保留质心—相对运动耦合的可能性。

ν = 1/3 的 Laughlin 态可作为基线：

$$
\Psi_L\propto\prod_{i<j}(z_i-z_j)^3\exp\left[-\frac14\sum_i|z_i|^2\right],\qquad
M_L=\frac{3N(N-1)}2.
$$

这不是 κ = 100 的已知答案，M_L 也不应直接赋给所有数据组。[Laughlin，Anomalous Quantum Hall Effect](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.50.1395)

### 3.4 用短程库仑 cusp 约束径向相关，避免固定三阶零点

由本节哈密顿量的相对坐标短程展开，相对角动量为 ℓ 的分量在 r → 0 时应满足

$$
\psi_\ell(r,\vartheta)\sim r^{|\ell|}e^{i\ell\vartheta}
\left[1+\frac{\kappa}{2|\ell|+1}r+O(r^2)\right].
$$

这里 r 以 l_B 为单位；系数来自相对动能 `−∇²_r` 与 `κ/r` 奇异项的抵消。此式是针对当前无量纲模型的推导，不能直接混用三维原子单位中的同自旋 cusp 常数。二维短程 cusp 和 ℓ = 1、3 分量共存的讨论可参考该论文的第四节与补充材料。[二维库仑 cusp 的原始推导与讨论](https://arxiv.org/html/2412.00618v2)

自旋极化只要求交换为奇，不强制所有粒子对都有三阶零点。特别是 N > 2 时，把 `∏(z_i−z_j)^3` 固定为所有候选的公共因子，会排除近碰撞处存在一阶零点的态。应比较不同零点结构，并在固定旁观电子位置后，对粒子对相对角度做分解，辨识实际占优的奇数 ℓ。

## 4. 数据准备与 teacher 态诊断

### 4.1 已有数据的实际情况

本次只读检查发现：

| 数据 | 位置 | 样本数 | 幅度权重有效样本数 |
| --- | --- | --- | --- |
| N = 2，κ = 100 | 仓库内 `datasets/disk_n2_Q6_kapa_100/dataset_uniform.npz` | 50,000 | 约 1641.61 |
| N = 2，目录标记 κ = 1 | 相邻目录 `../datasets/disk_n2_Q6_kapa_1/dataset_50000.npz` | 50,000 | 约 12745.30 |
| N = 6，目录标记 κ = 1 | 相邻目录 `../datasets/disk_n6_Q18_kapa1/dataset_uniform_4096.npz` | 4096 | 约 35.35 |

有效样本数按 `w_s = |psi_scaled_s|²` 和 `ESS = (Σw_s)²/Σw_s²` 计算，仅表示这些导出点上幅度权重的集中程度，不是 MCMC 自相关 ESS，也不是完整统计误差估计。目录中的 κ 标签仍需用原始训练配置核实：已有 JSON 未显式保存 κ，不能仅凭名称确认。

现有 NPZ 已有 `train_indices`、`test_indices`、`logpsi`、`log_abs`、`phase` 等字段，但当前评估器没有使用划分索引。已被全数据搜索使用过的样本不能事后重新宣称为未见测试集。最终验收需从同一 checkpoint 重新采样，另用独立 teacher 训练种子检查目标态的一致性。

目前仓库内只见到 N = 2、κ = 100 的主数据；未见完整 N = 2–6、κ = 100 数据族或固定 N 的 κ 扫描数据。N = 6、κ = 1 数据只能作为数据管线检查，不能充当 N = 6、κ = 100 的标签。`strength5`、`strength10` 等旧目录也不能未经核对便解释为 κ = 5、10。

### 4.2 每个数据组必须记录的元数据

新增统一 manifest，记录每组的：N、κ、ν、d/l_B、a_N/l_B、磁通 Q、规范、`z = x − iy` 约定、坐标和能量单位、自旋、训练配置摘要、checkpoint、teacher_seed、能量及误差、M 和角动量分布、采样分布 q、采样/链种子、样本来源编号、标签缩放常数、split 和文件哈希。

建议同时保存复数 `logpsi` 与直接波函数标签，并尽可能采用 float64/complex128。高 κ、近碰撞和节点附近的数值误差尤其需要检查。每个数据文件的 `psi_scaled` 应使用一个固定缩放常数；分批导出时保存并还原每批 log_shift，不能把不同缩放后的批次直接拼接。

候选不能读取 manifest 或数据文件；评估器加载它们，并只向候选提供允许的物理输入。

### 4.3 先确定 teacher 是否代表同一个可比较的态

每个训练条件建议至少 3 个独立 teacher 初始化；需要时从相邻 κ 双向暖启动，并保留独立冷启动结果。比较能量、方差、密度、角动量及 checkpoint 稳定性，再选目标态。

对每个 teacher 检查：

1. 交换坐标后是否变号；对多个粒子对、多个坐标区域测量。
2. 在共同坐标配置上查询旋转后的波函数，扫描多个 φ，并做旋转 Fourier 分解，估计各整数 M 的权重。
3. 测量角动量方差或 Fourier 谱集中度；平均角动量接近整数本身不足以证明纯角动量态。
4. 比较径向密度、粒子对距离分布、条件粒子密度、近碰撞相位绕数与能量。

若 teacher 明显混合多个 M，优先改进训练或分支约束；也可将旋转投影后的分量作为明确标注的独立研究对象。不能把“teacher 原态”和“teacher 的单 M 投影态”视为同一标签目标。只持有离散 NPZ 时无法可靠完成任意旋转、近碰撞及新 κ 查询，需要原始 NN checkpoint 和推理接口。

### 4.4 采样和划分

每组先准备约 50,000 个基础配置作为起步规模，并在能量与物理 fidelity 的误差仍大时扩充。N 较大或 κ 较高时，样本量由 ESS 和独立重复结果决定，不能仅沿用固定行数。

- 均匀圆盘采样：用于与现有实验对照和覆盖整个坐标域，保存截断半径与归一化密度。
- NN 的 `|Ψ_NN|²` 采样：覆盖主要概率质量，适合物理 overlap 与能量检查。
- 已知密度的独立广域 proposal：如二维高斯乘积，与上述分布组合以覆盖尾部。
- 专用审计配置：近碰撞、节点、质心偏移和尾部，单独报告，不直接混入无权重 fidelity。

若混合均匀与 NN 采样，需使用真正的混合 proposal 密度及组分归一化，或分别估计再合并积分；不能直接给不同来源样本相同权重。NN-only proposal 可估计支持集上的 overlap，但还需广域 proposal 检查候选在 teacher 节点及低概率区域之外的额外概率质量。

每个已知条件的基础配置建议划分为拟合 60%、验证 20%、测试 20%。MCMC 按独立链或轨迹块划分，旋转/交换增强按同一个 `source_id` 归组，禁止增强副本跨 split。未见 N 或 κ 的所有标签不参与联合形状拟合。

## 5. 统一波函数的候选表达族

建议首先研究以下通用形式，同时让各岛保留其他结构探索：

$$
\boxed{\Psi_N(\mathbf z;\kappa,\boldsymbol\theta)
=\mathcal C_{N,\kappa}\,
\mathcal A_{N,M}(\mathbf z,\bar{\mathbf z};\kappa,\boldsymbol\theta_A)
\,\mathcal S_N(\mathbf z,\bar{\mathbf z};\kappa,\boldsymbol\theta_S)}.
$$

这里 A 必须反对称且有确定旋转标签；S 必须对称且为旋转标量，可以为复值，因此允许旋转不变的关联相位。C 只处理整体复系数。此形式用于组织候选，不能预设 A 的零点结构或要求所有候选采用指数相关。

### 5.1 坐标尺度和不变量

保留磁长度尺度 `r_ij = |z_i−z_j|`，同时引入有限圆盘尺度：

$$
\xi_i=z_i/a_N,\qquad s_i=|\xi_i|^2,\qquad
u_{ij}=|z_i-z_j|^2,\qquad \tilde u_{ij}=u_{ij}/a_N^2,\qquad Z_{\rm cm}=N^{-1}\sum_i z_i.
$$

两种尺度都保留：r_ij 描述短程 cusp 和磁长度附近相关，ξ_i 描述边界及有限尺寸变化。不能只把全部粒子对距离除以 √N，因为这样会掩盖不随圆盘半径变化的局部物理尺度。

允许 `Σ_i f(s_i)`、`Σ_{i<j} g(r_ij, s_i+s_j, s_i s_j)`、`|Z_cm|²`，以及对称的三体形状函数。区分原始求和、按 N 平均、按粒子对数平均的结构，让模型比较其尺度规律；不要无条件把所有成对项除以 N²，这会改变短程 cusp 与相关强度。

### 5.2 候选族 I：奇数幂粒子对因子 × 对称修正

$$
\Psi_N^{(I)}=\prod_{i<j}(z_i-z_j)^q\,S_N,\qquad q\in\{1,3,5,\ldots\}.
$$

当 S_N 为旋转标量时，此族固定 `M = qN(N−1)/2`，只能用于匹配相应 M 的数据。q 是离散结构选择，不能拟合为连续的 q(κ)；非整数复幂可能造成多值性并破坏交换性质。

可比较低阶多项式、无实域极点的有理修正、距离乘积与短指数相关。q = 3 用作基线，q = 1 和更灵活结构用于检查是否需要不同节点。若为一般反对称态除以 Vandermonde，商可能在节点处不光滑，不能据此宣称光滑 S_N 足以表示所有实空间费米态。

### 5.3 候选族 II：具有固定角动量的 Slater–相关态

$$
\Psi_N^{(II)}=
\left[\sum_{a=1}^{K} c_a(N,\kappa)\det_{i,b}\phi_b^{(a)}(z_i,\bar z_i;N,\kappa)\right]S_N.
$$

轨道可包含 `z^m z̄^n f(|z|²)`，其中 m、n 为非负整数。每一列的旋转标签为 m−n；同一行列式的 M 是各列标签之和。所有相加的行列式必须具有同一个 M。通过径向函数允许 Landau 能级混合，通过多个行列式增加节点表达能力。

先用 K = 1、2、3 比较精度与复杂度。一般 N 的轨道数量可以随 N 增长，但轨道生成规则、径向核及共享系数应固定；逐个电子数保存自由轨道列表和自由系数不属于强意义的统一模型。

### 5.4 候选族 III：置换等变回流

$$
w_i=z_i+\sum_{j\ne i}(z_i-z_j)\,
\eta(r_{ij},s_i,s_j;N,\kappa),\qquad
\Psi_N^{(III)}=\det_{i,b}\phi_b(w_i,\bar w_i)\,S_N.
$$

η 为所有粒子共享的旋转标量核，按标签相同的规则生成 w_i。这样交换电子会交换行列式的两行；整体旋转时 w_i 与 z_i 同样变换。角动量仍由轨道列的整数标签约束。该族有助于检验“仅修正幅度”是否不够，而需要改变相位和节点。

### 5.5 候选族 IV：角动量投影的局域分子态

若条件粒子密度显示明显壳层或多边形关联，可以测试局域轨道行列式，并恢复旋转对称性：

$$
\Psi_{N,M}^{(IV)}=\mathcal P_M[\det\phi_b(\mathbf r_i;\mathbf R_b)]\,S_N,\qquad
\mathcal P_M f=\frac1{2\pi}\int_0^{2\pi}e^{iM\phi}f(\{e^{-i\phi}z_i\})\,d\phi.
$$

局域中心 R_b 的壳层规律需由当前圆盘势确定。旋转投影的思路有现成的旋转电子分子研究基础，但抛物势量子点中的参数和壳层结果不能直接移植到本项目的带电圆盘势。[Li、Yannouleas 与 Landman，Properties of rotating electron molecules with multiple rings](https://arxiv.org/abs/cond-mat/0601034)

此族作为第二阶段候选：数值积分仅用于评估假设，并检查积分点数收敛与角动量混叠；最终优先化简成有限解析展开。若只能保留投影积分，应标注为“解析试探态及其数值求值”，不要当作已经得到初等闭式公式。

### 5.6 一个可检查的相关核起点

对称相关部分可从以下短形式开始：

$$
S_N=\exp\left[-\alpha(N,\kappa)\sum_i|z_i|^2
+\sum_{i<j}\frac{c(N,\kappa)r_{ij}}{1+b(N,\kappa)r_{ij}}\right].
$$

α > 0 保证此起点的高斯尾部，b ≥ 0 避免距离域上的极点。如果反对称部分在某对近碰撞处由单一 ℓ 分量主导，则短程一致性要求该分量的 c = κ/(2|ℓ|+1)；多个 ℓ 并存时，单一共用 c 不足以保证所有分量的 cusp。

这只是低成本基线，不能用它代替结构发现。应与非指数修正、混合坐标结构和回流族比较；特别要检验删除额外相关项后精度是否保持。

| 2 | 6 | √12 | 3 |

| 5 | 15 | √30 | 30 |
| 6 | 18 | 6 | 45 |

最后一列只是参照值。首先测量训练和验证 N 的实际 M_N(100)，确定能否由同一角动量生成规则描述。测试 N 的 teacher 可由独立管线完成质量审计，但其 M、节点和拟合结果应在候选冻结后揭示。若某个 N 的基态落在不同壳层或不同 M 序列上，应把它当作物理信息，不能为了统一强行修改标签。

### 6.2 分阶段搜索

**A0：单条件基线。** 先在训练/验证电子数 N = 2、3、4、5 上分别搜索，获得本体系的 Pareto 前沿、M、节点/绕数、主要距离尺度及关键相关核。N = 6 的独立拟合基线在统一模型冻结后另行计算，不反馈给结构选择。独立拟合只用于建立上限和结构假设，不构成最终统一结果。

**A1：共享结构、常系数。** 在 N = 2、3、5 上联合拟合同一模板和一组 θ，使用 N = 4 做模型选择，N = 6 保留为整条件测试。只有各组的全局复系数可以分别对齐。

**A2：引入简洁有限尺寸规律。** 若常系数不足，允许少量系数使用例如

$$
\alpha(N)=\alpha_0+\frac{\alpha_1}{N},\qquad
b(N)=b_0+\frac{b_1}{\sqrt N},
$$

并与零修正比较。这些仅为待检验的函数族，不是已知有限尺寸定律。禁止 N 分支查表、用五点高阶插值以及参数量随 N 无约束增长。

**A3：角动量规律。** 强统一模型必须给出确定的轨道/角动量生成规则，使 M_N 由 N 计算。候选规则只在训练和验证 N 上确定，不允许查询测试波函数后再选 M。如果只能把测得的 M 当作额外输入，结果应明确写成“条件于 (N, M) 的统一波函数族”，这比仅输入 N 的目标弱。

**A4：盲测和扩展。** 冻结公式、共享系数和 M 规则，在 N = 6 上计算所有指标，不再优化形状参数。随后新增 N = 7、8 的 teacher 做真正外推验证。可补做 N = 2–6 的留一电子数交叉验证来检查对训练组合的敏感性，但完成主盲测后不能用其结果反复调参并继续称 N = 6 为盲测。

若跨 N 联合精度明显差于各组独立拟合，依次诊断：坐标尺度是否正确、M 规律是否错误、短程零点是否被固定、质心耦合是否缺失、三体相关是否必要。只有这些证据支持时才增加结构复杂度。

## 7. 实验 B：固定 N，发现显式 κ 依赖

### 7.1 κ 采样网格和整条件留出

建议先在 N = 2 上验证流程，再使用 N₀ = 4 做主实验。按每个 κ 独立训练或可靠连续追踪 teacher；不能由 κ = 1 和 100 的标签线性插值得到中间 κ 的真值。

| 用途 | 第一轮建议 κ |
| --- | --- |
| 拟合条件 | 1、2、3、5、10、20、50、100 |
| 模型选择条件 | 4、8、15、35、70 |
| 冻结后测试条件 | 1.5、6、12、30、60、90 |

该网格同时覆盖低 κ 和强混合范围，并检验非整数 κ。κ = 1 也不等价于 κ ≪ 1，若要检验严格弱混合极限，可另加 κ = 0.1、0.3 的控制实验，明确它们不属于主扫描范围。

发现异常能量或 M 变化后，在对应区间补充训练/验证 κ，定位分支边界。补点应在冻结前完成；若原测试结果用于改变模型，需另设新测试条件。

研究目标为连续区间 [1,100]；有限网格只能验证部分点。主模型冻结后，预算允许时完成 κ = 1、2、…、100 的逐整数独立验证，并列出训练点与未见点。若未完成，应明确实际验证的 κ 范围和点数。

### 7.2 学习系数规律，并保持 κ 为物理输入

先仅在训练/验证 κ 上独立拟合同一结构，观察 α(κ)、b(κ)、回流强度或同 M 行列式混合系数的变化；再把这些趋势压缩为低复杂度函数，并用所有训练 κ 联合拟合函数中的共享系数。测试 κ 的独立拟合对照只在统一模型冻结后计算。

可比较的低成本函数族包括

$$
\alpha(\kappa)=a_0+a_1\frac{\kappa}{1+\kappa},\qquad
b(\kappa)=b_0+b_1\log\kappa,\qquad
\eta(\kappa)=c_0+c_1\frac{\kappa}{\kappa+c_2}.
$$

同时检查正性、无极点、端点行为和量纲。短程 cusp 条件中已知的 κ 依赖应由物理结构表达，不必全部自由拟合。

数值优化可采用 `t = log(κ)/log(100)` 等无量纲输入变换。固定尺度 100 来自预声明实验范围，不是拟合参数；变换必须显式记录并计入公式说明和复杂度，不能藏在未计价的特征预处理里。连续的复坐标幂和随 κ 连续变化的角动量标签不允许进入单分支候选。

### 7.3 先判断“一个连续公式”是否符合物理

**情况一：M 在 κ ∈ [1,100] 上不变。** 在同一 M 内搜索非全纯核及同 M 多行列式的连续 κ 依赖，目标为一组共享系数的单一解析族。若同 M 内发生快速重排，可以增加少量连续混合项，但需要未见 κ 和能量验证。

**情况二：不同 M 的基态分支发生交叉。** 对旋转对称模型，不同 M 分支不能用任意连续混合来表示一个仍具有确定 M 的基态。此时分别学习各分支 Ψ^(b)(κ)，并通过分支能量交叉确定物理分界：

$$
\Psi_{\rm gs}(\kappa)=\Psi^{(b_*(\kappa))}(\kappa),\qquad
b_*(\kappa)=\operatorname*{arg\,min}_b E_b(\kappa).
$$

最终给出紧凑分段表达、交叉点误差和有效区间；它是统一的基态选择规则，但通常不是在整个 κ 区间光滑的单一波函数。交叉点处可能简并，应报告相关分支。不可用 sigmoid 混合不同 M 后仍宣称保持单一角动量。

**情况三：希望强制连续追踪一个态。** 可固定 M 跟踪同一分支，包括它在某些 κ 上成为激发态的区域；此时研究目标应明确写成“连续态分支”，而不是全区间基态。

LL 混合可能驱动液体与晶体的竞争，支持首先识别分支的设计；本项目的临界 κ 仍需单独测量，不能套用其他几何、厚度或粒子数的相图。[Zhao、Zhang 与 Jain，Crystallization Induced by Landau-level Mixing](https://arxiv.org/abs/1801.06695)

## 8. 联合拟合、评分与物理验证

### 8.1 分组处理全局复系数

令 g 表示一个物理条件/teacher 数据组，f_g(θ) 为候选，y_g 为 NN 标签，w_s 为积分或拟合权重。每组的全局复系数可解析消除：

$$
c_g(\theta)=\frac{\sum_s w_s f_{g,s}^*y_{g,s}}{\sum_s w_s|f_{g,s}|^2},\qquad
L_g(\theta)=\frac{\sum_s w_s|c_gf_{g,s}-y_{g,s}|^2}{\sum_s w_s|y_{g,s}|^2}.
$$

联合损失使用 `L_joint = (1/G) Σ_g L_g`，每个条件等权，避免一个标签缩放、样本数或波函数范数大的组主导拟合。若同一物理条件有多个 teacher，先在该条件内平均，再对物理条件平均，避免重复训练次数改变条件权重。拟合仅使用训练数据，验证只用于模型选择，最终测试只用于冻结后的报告。

训练、验证、测试中全局相位和范数的对齐只是物理无关自由度的消除，不是形状参数重新拟合。若要研究 κ 导数或相邻 κ 的相位连续性，则需要另设一致的跨 κ gauge；逐组相位对齐不足以支持此类结论。

### 8.2 区分样本 fidelity 与物理 Hilbert 空间 fidelity

当前无权重点积计算的 fidelity 衡量导出样本分布上的相似度；均匀采样仅在截断坐标域内对应积分。对 q(R) 采样，物理 overlap 的重要性估计使用 w_s ∝ 1/q(R_s)：

$$
F_g^{(w)}=\frac{|\sum_s w_s f_{g,s}^*y_{g,s}|^2}
{(\sum_s w_s|f_{g,s}|^2)(\sum_s w_s|y_{g,s}|^2)}.
$$

对纯 `|y|²` 采样，也可用比值 `R=f/y` 的估计 `|⟨R⟩|²/⟨|R|²⟩`，在支持与方差受控时消去未知 proposal 归一化。两种估计都需要检查尾部、节点附近比值和有效样本数；NN 缩放常数在各组归一化 overlap 中会抵消。

按独立样本块/链 bootstrap 给出误差和置信区间，并检查积分域或广域 proposal 扩大后的收敛。专用近碰撞配置可做局部误差和 cusp 审计，不应直接改变物理积分测度。

### 8.3 保留 Pareto，先满足物理有效性

建议新任务采用“对称性/可积性/实域奇异性有效门槛 + 精度—复杂度 Pareto”。物理门槛由结构编译器与独立审计完成，不把对称性误差混入精度的连续惩罚项；当前单条件评估器保持原行为，作为基线。

有效候选的 LoongFlow 标量桥接分数可用

$$
\mathrm{score}=\frac1G\sum_g F_{g,\rm val}^{(w)}\,p_{g,\rm finite}.
$$

并列记录最差组 fidelity、各组分数和不确定度，防止平均值掩盖某个 N 或 κ 的失败。测试数据永不进入演化反馈或 Pareto 选择。

复杂度继续独立记录，不乘到 score 上。通用模板至少报告：核表达式树节点数、轨道/整数标签生成规则、κ/N 参数规律、所有拟合系数、行列式项数及完整子表达式。额外报告每个 N 的展开规模和实际耗时。`pair_sum` 或 `det` 的整个复杂结构不能免费隐藏为一个节点；使用模板复杂度时需声明与旧的展开 AST 复杂度是不同口径。

不同 N 的纯展开表达式长度不能直接比较为“同一物理结构变复杂了”。同时也不能以短模板掩盖大量自由轨道或高计算成本。保留最大精度、Pareto 膝点、低复杂度代表与完整前沿。

### 8.4 验证指标与可解释性

每个已见/未见条件至少报告：

| 类别 | 指标 | 作用 |
| --- | --- | --- |
| 拟合 | 样本 fidelity、重要性加权 fidelity、加权 NMSE、最差组结果 | 检查数值形状与跨条件预测 |
| 数值 | finite_fraction、节点/尾部行为、边界命中、优化重复性 | 避免不稳定公式 |
| 对称性 | 交换误差、旋转协变误差、M 分布/方差 | 检查费米与旋转约束 |
| 结构 | 节点、绕数、近碰撞 ℓ 分解、cusp | 检查公式是否捕获正确局部物理 |
| 观测量 | 径向密度、粒子对距离分布、条件密度 | 判断液体/壳层关联 |
| 能量 | E、局域能量方差、分支能量差 | 验证物理质量与基态选择 |
| 简洁性 | 模板复杂度、参数数、行列式数、耗时 | 判断是否仍是有解释力的解析模型 |

交换和旋转误差采用整体归一化二范数，而非逐点除以 Ψ，避免节点附近虚假发散。审计既检查候选也检查 teacher，并区分它们的误差来源。

能量须用同一个含磁场、背景势和全 Hilbert 空间的 H，最好从候选自己的 `|Ψ_θ|²` 分布采样：

$$
E_L(R)=\frac{H\Psi_\theta(R)}{\Psi_\theta(R)},\qquad
E_\theta=\operatorname{Re}\langle E_L\rangle_{|\Psi_\theta|^2},\qquad
\sigma_E^2=\langle|E_L-E_\theta|^2\rangle.
$$

还需检查平均虚部与数值微分误差。对磁场体系不能只对 |Ψ| 求导而忽略复相位。短程能量涉及二阶导数，可用解析导数或另行实现的自动微分；若新增 JAX 等库，将其放在实验级 requirements，保持 SDK 通用。

与 NN 比较 `δe = (E_θ−E_NN)/(N E_C)` 及其统计误差。NN 是变分参考，不是已知精确基态；候选能量低于 NN 可能是改进，也可能是数值问题，需要复核，不能机械地判为错误。高 fidelity 也不自动保证能量准确。

7. **配置层**：更新物理输入说明、共享参数限制、六岛结构种子、整条件留出规则以及测试数据禁读规则。

PES 分工保持：Planner 提出结构假设与删项/重置策略；Executor 实现受限候选并进行训练/验证评估；Summary 总结跨条件证据、失败组与复杂度变化。离线 teacher 训练和最终测试由独立实验管线管理，测试结果不反馈给当前搜索。

### 9.2 预算与必要检查

先以 20–30 次候选评估测量成本，再建议每项主实验投入 100–300 次有效候选评估、至少 3 个独立演化运行。记录每次预算是全局还是每岛，并检查每个岛的实际候选数。当前默认 5 次迭代适合冒烟检查，不足以作为结构发现的充分证据；这些建议数字也不保证收敛。

保持总共享拟合系数起步不超过 15 个；按验证证据增加，而不是每个条件各获得 15 个。保留低复杂度结构重置，避免所有岛只追随同一指数核。停止依据为验证前沿、最差组与结构稳定性，不只依据单个平均分数超过 0.995。

实现后需要的针对性验证包括：已知合成反对称态的跨 N/κ 恢复、物理输入不会被拟合、交换/旋转约束、带权积分估计、组间缩放不变性、split 增强泄漏检查、未见条件不重新拟合、存档身份一致性。使用项目要求的 Python 3.12+ 与 uv，运行对应 `uv run pytest` 检查。

## 10. 消融、验收和交付

### 10.1 必做的结构对照

在相同数据、预算和选择规则下比较：

- 原来的单条件模型，与共享结构/共享参数模型：衡量统一带来的精度代价。
- 共享常系数，与少量 N 或 κ 系数规律：检验显式参数依赖是否必要。
- 纯全纯基线，与非全纯结构：检验 Landau 能级混合的表达需求。
- q = 3 固定零点，与允许一阶零点/灵活节点的模型：检查 Laughlin 因子是否过度约束。
- 幅度相关，与回流或同 M 多行列式：检查是否必须改变相位和节点。
- 一体/二体模型，与有证据支持的三体修正：判断高阶关联的必要性。
- 无权重全数据分数，与独立带权测试：估计现有评分与物理质量之间的差异。

### 10.2 预声明的参考验收标准

以下是起步目标，应在主搜索前根据 teacher 重复性和 Monte Carlo 误差冻结，不能事后随测试结果降低：

| 项目 | 建议要求 |
| --- | --- |
| 跨条件预测 | 测试时不重拟合形状参数，不查询 NN 决定候选结构或 M |
| 数值有效性 | 科学测试配置上无非有限输出；尾部可积、实域无意外极点 |
| 对称性 | 代数构造有证明；float64 整体相对误差目标 ≤ 10⁻⁸，病态配置单列 |
| 未见条件 fidelity | 起步争取每组 F ≥ 0.99；置信区间、最差组及 teacher 噪声必须并列报告 |
| 能量 | 起步争取 `|δe| ≤ 0.01`，并核查方差、参考误差与有限样本收敛 |
| 简洁性 | 完整公式、参数规律及轨道规则可复现；在 Pareto 前沿保留更短替代式 |
| 稳定性 | 至少 3 个独立搜索结果，关键结构和物理解释可复现 |
| 适用范围 | 明确已测试 N/κ、态分支、外推范围及失败条件 |

不能因为拟合全数据上 F > 0.995，就宣称得到了任意电子数或全部 κ 的波函数。若统一模型只在一个态分支上成立，按这个范围验收并报告；分支切换本身可以成为有价值的物理结果。

### 10.3 分阶段交付

| 阶段 | 主要产物 | 进入下一阶段的条件 |
| --- | --- | --- |
| P0：teacher 和单位审计 | manifest、N/κ 数据清单、M/能量/采样诊断 | 物理输入已核实，目标态可比较 |
| P1：接口与合成验证 | 变长坐标、物理参数输入、联合评估、数据隔离 | 合成态恢复与物理门槛通过 |
| P2：实验 A | 跨 N 候选、系数/M 规则、N = 6 盲测 | 共享模型在未见 N 上通过验证或明确失败原因 |
| P3：实验 B | 显式 κ 公式、分支图与未见 κ 测试 | 识别连续分支/交叉，不用分支混合掩盖失败 |
| P4：独立物理验证 | N = 7/8、额外 κ、能量/密度/节点对照 | 报告适用边界与统计误差 |
| P5：最终整理 | 完整 Pareto 前沿、三类代表公式、可复现配置和研究报告 | 公式、共享系数、所有限制均公开 |

建议报告至少包含：F—复杂度前沿、各 N/κ 的未见条件误差、M(κ) 和分支能量、径向/条件密度、近碰撞绕数/cusp、共享系数规律及运行成本。所有图表都注明训练、验证和测试点。

最终希望得到两类交付物：`Ψ_N(z₁,…,z_N;κ=100)` 与 `Ψ_{N₀}(z₁,…,z_{N₀};κ)`，包含完整结构、固定共享系数、整体归一化约定、M/轨道生成规则及有效范围。若闭式初等函数不可得，可交付经过验证的短行列式/投影试探态，并如实说明表达形式。

## 11. 两项实验完成后的扩展与边界

两条轴上的成功不会自动证明联合 `Ψ_N(κ)` 成立。可以把它作为第三项研究，在稀疏 `(N,κ)` 网格联合训练，并留出整个组合，例如 N = 5、κ = 20；随后检查不同 N 的分支边界。不能直接拼接两项实验的系数规律后宣称全参数统一。

若原始电子数列表实际包含 N = 34，建议先完成 N = 2–6 的局部机制研究，再把 34 作为大体系验证任务。N = 34 有 561 个粒子对；求和/乘积约 O(N²)，单行列式约 O(N³)，显式 N! 反对称化应避免。teacher 训练、重要性采样、壳层变化和相近 M 分支会成为主要成本，需要独立扩大预算。N = 7、8 的成功也不能代替对 N = 34 的检查。

本方案最大的科学风险是：有限尺寸或 κ 扫描跨越不同角动量/壳层分支，以及极强混合下采样不足。对应的处理是先诊断分支、再搜索共享结构、通过独立样本和能量验证，而不是用越来越长的表达式掩盖不一致。
