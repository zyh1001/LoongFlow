PHASE 1: MATHEMATICAL DEFINITION
--------------------------------------------------------------------------------
VARIABLES
  X_discrete = m  in {1,3,5,7,9}  (odd Laughlin exponent; a structural literal,
                                    NOT a fitted parameter, must stay odd).
  X_cont     = (alpha, gamma)     (fitted real parameters with finite defaults).

STRUCTURAL OBJECTS (N = 6 -> 15 pairs)
  d_ij = z_i - z_j ,  i < j
  J    = prod_{i<j} d_ij                 # Vandermonde numerator
  S    = sum_i |z_i|^2                   # rotational invariant
  G    = |sum_i z_i|^2                   # center-of-mass rotational invariant

CANDIDATE (to be written inside EVOLVE-BLOCK)
  Psi(z; alpha, gamma) = J^m * exp( -alpha*S - gamma*G )
  with the submitted topology m = 3 (the minimal odd exponent consistent with
  Phi = N*Phi0/nu, nu = 1/3):

          Psi = J^3 * exp( -alpha*S - gamma*G ),   alpha=0.25, gamma=0.0 (defaults)

CONSTRAINTS C (hard, satisfied constructively)
  C1  ANTISYMMETRY.  Exchange i<->j sends d_ij -> -d_ij, hence J -> -J.  Because
      m is ODD, J^m -> -J^m; S and G are exchange invariant.  Therefore
      Psi(...,r_i,...,r_j,...) = -Psi(...,r_j,...,r_i,...).         [PROVED]
  C2  SINGLE ANGULAR-MOMENTUM SECTOR.  z_i -> e^{-i phi} z_i gives
      J^m -> e^{-i phi * m * N(N-1)/2} J^m = e^{-i phi * m * 15} J^m; both S and G
      are invariant.  So Psi lies in the pure sector
      M = m * N(N-1)/2 = 3 * 15 = 45.                                [PROVED]
  C3  FINITENESS.  alpha = 0.25 > 0 makes the Gaussian decay at infinity and J^m
      is polynomial; the returned array is finite for every finite sample
      (=> finite_fraction = 1).
  C4  REPRESENTATION LEGALITY.  Only the integer literal 3 (|.|<=12) and integer
      powers appear; NO decimal literal in the return expression; the only
      non-structural constants alpha, gamma are named fitted parameters with
      finite defaults; the return value is a vectorized numpy expression
      (not a dict / string).

OBJECTIVE f(X)
  maximize   accuracy(X) = fidelity(X) * finite_fraction(X)  ;
  minimize (conceptually)  L(X) = 1 - fidelity(X) ,
  evaluated on the fixed 50000-sample full-data pool.
