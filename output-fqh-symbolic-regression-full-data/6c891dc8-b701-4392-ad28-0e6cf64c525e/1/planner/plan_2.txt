PLAN 2
=====================================================================
Title: Constraint-Filtered Basis Pursuit (Convex Linear Least Squares over
       Enumerable Antisymmetric Single-M Building Blocks)
=====================================================================

1. MATHEMATICAL DEFINITION
--------------------------
Variables: coefficient vector X = (c_1,...,c_K) in R^K (or C^K via (re,im)
pairs), K <= 15.
Building blocks B_k(z1,z2): monomials/invariants generated from
   z_ij = z1-z2, conj(z_ij)=z1c-z2c, r2=|z_ij|^2, R2=|z1+z2|^2,
   Z=z1+z2.
Candidate:  Psi = sum_k c_k B_k .
Constraints C:
   C1 each B_k must satisfy exchange parity (-1)^{a_k+b_k} = -1.
   C2 each B_k must carry the SAME angular momentum M (single sector):
      (a_k - b_k) = M for all k.
   Filter: keep only B_k with (a_k+b_k) odd AND (a_k-b_k)=M. This removes
   cross-sector leakage, guaranteeing the sum is still a single M sector.
Objective f(X) = fidelity(X)*finite_fraction(X) -> maximize.
Key property: Psi is LINEAR in X, so f (after a global renormalization) is
a Rayleigh-quotient / least-squares problem -> CONVEX in X.

2. SOLVER STRATEGY
------------------
- Discrete structure search: choose M in {1,3,5}; enumerate all B_k with
  total holomorphic degree a_k in [M, M+4], antiholomorphic degree
  b_k = a_k - M, built from the invariant dictionary; cap K<=15.
- Continuous solve: for the admissible basis, X* = argmin ||A X - y||_2^2
  solved by np.linalg.lstsq(A, y) (normal equations; unique global optimum
  for a given B-set). Add a tiny ridge lambda=1e-8*I for conditioning.
- Multi-start: run the discrete enumeration for BOTH M=3 (primary) and
  M=1,5 (fallbacks), and for basis sizes K in {1,2,3,5}; keep the global
  best accuracy. (>=20 independent structural restarts; deterministic
  once the random sample split seed is fixed.)

3. VALIDITY MECHANISM (Safety Valve)
------------------------------------
- The parity/angular-momentum FILTER (step C1/C2) is applied BEFORE the
  solve, so antisymmetry and single-sector covariance hold by construction
  for any X.
- Sympy check (offline): verify exch(Psi)+Psi==0 and rot-check
  Psi(z->tz, conj z->z/t) == t^{-M} Psi for the assembled sum.
- Numeric finite gate on a grid; drop any B_k producing NaN/Inf.
- Hard fallback: if the solver fails or accuracy<=baseline, return
  Psi=(z1-z2)^3 (guaranteed antisymmetric, M=3, finite).

4. WHY THIS PLAN
----------------
+ Global optimum of the parameters is guaranteed by convexity (no luck).
+ Fully decoupled: discrete structure enumeration vs exact linear solve.
+ Directly supports sparse/compact final form via L1 (LASSO) trimming.
- Risk: unconstrained linear fits can pick large coefficients that make the
  expression non-compact; needs the L1/trim step. Candidate syntax may need
  a hand-coded coefficient list (more nodes) -> higher complexity, though
  complexity does not reduce the scalar score.
