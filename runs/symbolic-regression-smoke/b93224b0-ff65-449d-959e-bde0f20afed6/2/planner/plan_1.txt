  C4 (budget)      <= 10 fitted numerical parameters

SOLVER STRATEGY
---------------
Two-level decoupling (structure = hard/discrete, parameters = easy/continuous):
  Level 1 (STRUCTURE, discrete enumeration + multi-start): iterate over S0..S3;
    each is a distinct, physically motivated hypothesis. This is the "multi-start"
    over the non-convex structural space.
  Level 2 (PARAMETERS, exact/least-squares, delegated to evaluator):
    For a FIXED structure the amplitude c0 enters LINEARLY (given the real envelope
    exponents), so the fit of (c0_re, c0_im) is a well-conditioned 2x2 linear
    least-squares normal-equation solve; the envelope exponents are 1-2 smooth
    nonlinear parameters. The evaluator runs a nonlinear least-squares
    (scipy.optimize.least_squares / Levenberg-Marquardt) starting from our
    physically motivated init values (a=0.25, b=0, d=0, ...).
  Selection rule: keep the structure that returns the highest evaluator score;
    ties broken by lower expression complexity.

VALIDITY MECHANISM (guarantees hard constraints)
------------------------------------------------
A deterministic validator runs on the candidate string BEFORE submission:
  1. Parse with sympy.sympify over an allow-list of symbols only
     (z1,z2,z12,abs,exp,I,pi, and the parameter names). Reject unknown names.
  2. EXCHANGE test: sample 10^4 random complex (z1,z2); assert
     |Psi(z2,z1)+Psi(z1,z2)| / (|Psi(z1,z2)|+1e-12) < 1e-8.
  3. ROTATION test: with phi random, assert
     |Psi(e^{-i phi}z1,e^{-i phi}z2) - e^{-i*3*phi}Psi(z1,z2)| ... < 1e-6.
  4. FINITENESS test: assert np.isfinite on 10^5 random points with |z_i| <= 6.
  5. Budget test: count fitted parameters <= 10.
Guaranteed-valid fallback F (provably satisfies all constraints):
   "c0 * z12**3 * exp(-0.25*(abs(z1)**2 + abs(z2)**2))"
If any candidate fails, or the evaluator returns status != "success",
return F. Because (z12)^3 is odd, F is exactly antisymmetric, has M=3, and is
finite everywhere -> physics_factor = 1 by construction.

WHY THIS SOLUTION
-----------------
+ Highest expected gain: adds the two structurally missing ingredients (correct
  odd power 3 and the Gaussian Landau envelope) -> fidelity should jump by orders
  of magnitude over the parent.
+ Transparent antisymmetry (odd power of z12) so exchange_error stays 0.
+ Low complexity (S0 has ~1 fitted param + 1 envelope exponent), so the
  complexity_penalty stays 1.
+ Structure/parameter decoupling makes the parameter fit well-conditioned and
  cheap, avoiding wasted evaluator budget.
- Advantage: robust, physics-anchored, low crash risk, simple code.
- Disadvantage: assumes the target is close to the Laughlin M=3 sector; if the
  true state has strong non-holomorphic structure, S2/S3 cover that but are less
  certain. Mitigated by enumerating the bank and keeping the best.
