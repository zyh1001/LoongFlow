PLAN 1 — Holomorphic Laughlin-type baseline with Gaussian (confinement) envelope
================================================================================

GOAL / TASK
-----------
Discover a compact analytic candidate Psi(z1,z2) that reproduces the target 2-electron
fractional-quantum-Hall neural wavefunction (N=2, nu=1/3, disk radius a/l_B=sqrt(12),
Landau-level-mixing lambda=5) measured by full-data NMSE / fidelity against the pool.
Target score >= 1.0.

MATHEMATICAL FORMULATION
------------------------
Variables:
  X = (c0_re, c0_im, c1)  in R^3        (continuous, fitted)
  Structural integers fixed: m = 3 (odd Power of z12), envelope exponent 1.

Expression (structure FIXED, parameters free):
  F(z1,z2; X) = c0 * z12**3 * exp( c1 * ( |z1|^2 + |z2|^2 ) )
  with z12 = z1 - z2, |z|^2 = abs(z)**2.

Objective (minimized by the evaluator; we only choose structure + init):
  f(X) = min_{s in C}  sum_s | s*s... 
       -> full_data_nmse = sum_k | s * F(x_k; X) - Psi_true(x_k) |^2 / sum_k | Psi_true(x_k) |^2
  where s is the complex global scale fitted jointly.

Constraints C (hard, enforced structurally):
  (i)  Fermionic antisymmetry: F(r2,r1) = -F(r1,r2)  <=  odd power (3) of z12  => exact.
  (ii) Angular-momentum eigenstate: z12^3 -> exp(-3 i phi) z12^3  => M = +3 (single integer).
  (iii)Finiteness on the whole plane: require Re(c1) <= 0 (Gaussian decays); bound c1 in [-1, 0].
  (iv) Parameter count <= 10 (here 3). No dataset access, no branching on index.

SOLVER STRATEGY
---------------
- Structure is chosen by us (fixed symbolic form). Parameters are tuned by the evaluator's
  scipy least-squares optimizer.
- Initialization (physics-informed, Laughlin value): c0_re = 1.0, c0_im = 0.0, c1 = -0.25.
  (Laughlin: exp(-(|z1|^2+|z2|^2)/4)  =>  c1 = -1/4.)
- Multi-start mandate: we initialize a SINGLE representative point (evaluator refits);
  to guard against a bad basin we additionally pre-screen locally (see Safety Valve).

VALIDITY MECHANISM
------------------
- Exact analytic guarantees: odd exponent => antisymmetry; monomial in z12 => single M=3.
- Bounds guarantee finiteness: c1 <= 0.
- Local numeric probe on a synthetic grid: evaluate F on z1,z2 in [-6,6]^2 (numpy) and assert
  np.all(np.isfinite(F)) and max|F| not astronomically large.
- Fallback: if any check fails, degrade to the guaranteed-safe candidate c0*z12 (parent form).

WHY THIS SOLUTION
-----------------
Expected gain: adds the missing Gaussian envelope exp(-r^2/4) (the single largest defect of the
parent) and corrects the relative factor to the nu=1/3 Laughlin power z12^3. These two ideas are
the dominant physics of the target state. Low complexity (3 params), transparent antisymmetry.
Advantages: minimal, physically exact, low overfitting risk, contains the correct LLL baseline.
Disadvantages: assumes a pure Laughlin/Gaussian structure; lambda=5 means LL mixing is strong, so
pure holomorphic Laughlin may leave residual error (secondary corrections needed later).
