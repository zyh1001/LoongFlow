**Objective:** Discover a compact analytic candidate Psi(z1,z2) that reproduces the target 2-electron fractional-quantum-Hall neural wavefunction (N=2, nu=1/3, disk radius a/l_B=sqrt(12), LL-mixing lambda=5) with **full-data fidelity high enough to reach score >= 1.0**. The parent `c0*z12` has fidelity ~2.2e-5 (essentially zero) because it lacks the Gaussian/confinement envelope and has the wrong relative power. We must make one large, physics-correct structural leap.

**Selected Outline:** Plan 3 — *Nested Laughlin core × relative Jastrow correction (LL-mixing aware) with graceful degradation*. The selected concrete child is the 4-parameter nested model
`F = c0 * z12**3 * exp( c1*(|z1|^2+|z2|^2) + c2*|z12|^2 )`,
which reduces EXACTLY to the safe Laughlin baseline when c2 = 0.

**Rationale for Selection:**
1. It is **nested**: c2 = 0 recovers `c0*z12**3*exp(c1*(|z1|^2+|z2|^2))` exactly, so the fitted result can never be worse than the safe baseline at the initialization point — this removes "luck" from the parameter search.
2. It fixes the two dominant physics defects of the parent in one structural edit: (a) the missing Gaussian envelope, (b) the wrong Laughlin relative power (1 -> 3 for nu=1/3, giving M=3).
3. Antisymmetry and integer angular momentum are **structurally exact** (odd power of z12), not fitted, so those hard constraints cannot be violated.
4. Finiteness is enforced by **hard bounds + a deterministic projection** on the Gaussian rates — a genuine "safety valve."
5. It stays within the compact/low-complexity regime (4 params <= 10).

  *Interpretation:* `z12**3` = antisymmetric relative-motion Laughlin factor (M=3); `exp(c1*(|z1|^2+|z2|^2))` = Gaussian confinement/Jastrow envelope (Laughlin value c1 = -1/4); `exp(c2*|z12|**2)` = rotationally invariant relative-correlation (LL-mixing) correction. Because `|z1|^2+|z2|^2 = 2|Z_cm|^2 + |z12|^2/2`, the pair (c1,c2) sets the relative rate (c1/2 + c2) and CM rate (2*c1) independently — an anisotropic-confinement generalization that still contains the isotropic Laughlin case (c2 = -c1/2).

* **Hard constraints C (enforced structurally / by projection):**

**Phase 3 — The "Safety Valve" (CRITICAL deterministic validity enforcement)**

This step runs deterministically and guarantees the submitted candidate is valid regardless of what the optimizer returns:

1. **Analytic hard-constraint audit (no randomness):** confirm (a) exponent of z12 is the odd integer 3 (=> antisymmetry + M=3); (b) all other multiplicative factors are functions of |.|^2 only (=> rotation invariance, no M contamination). These are checkable by construction of the string.
2. **Finiteness projection (exact repair):** after any parameter update, project the Gaussian rates into the feasible (non-growing) cone:
   * `c1 = min(c1, 0.0)`
   * `c2 = min(c2, -c1/2.0)`  (this is the only constraint that matters for decay at infinity; the CM rate 2*c1 <= 0 is implied by c1 <= 0).
   This is a deterministic clamp that can never produce an invalid (blowing-up) expression.
3. **Grid finiteness / magnitude probe (numpy):** evaluate F on a dense grid z1,z2 over [-6,6]^2; assert `np.all(np.isfinite(F))` and that the max magnitude is finite and bounded. If not, force c2 = 0 (fall back to the guaranteed core).
4. **Fallback candidate (always valid):** if any check fails, return the guaranteed-safe candidate
   `c0 * z12**3 * exp(c1*(abs(z1)**2 + abs(z2)**2))` with c1 <= 0.
5. **Interface guarantee:** ensure the returned dict has exactly the keys `expression` and `parameters`, and that every parameter appearing in the expression string is present in `parameters` (mirrors the parent's interface `{c0_re, c0_im}`).

def candidate_spec():
    # Nested Laughlin-core x relative-Jastrow model capturing the LL-mixing correction.
    #   z12 = z1 - z2 ; |z|^2 = abs(z)**2 ; convention z = x - i*y (fixed by task).
    #   F = c0 * z12**3 * exp( c1*(|z1|^2+|z2|^2) + c2*|z12|^2 )
    # Odd power (3) -> exact fermionic antisymmetry + single angular momentum M = +3.
    # c1 = -1/4 is the exact Laughlin Gaussian rate; c2 = 0 keeps the safe nested baseline.
    # Hard constraints (applied by the design of the form + projection):
    #   finiteness  <=>  c1 <= 0  and  c2 <= -c1/2   (both Gaussian rates <= 0).
    c1 = -0.25          # Gaussian/confinement rate (Laughlin value)
    c1 = min(c1, 0.0)   # finiteness projection
    c2 = 0.0            # relative-Jastrow (LL-mixing) correction, off at init
    c2 = min(c2, -c1 / 2.0)  # finiteness projection: c1/2 + c2 <= 0
    return {
        "expression": "c0 * z12**3 * exp(c1*(abs(z1)**2 + abs(z2)**2) + c2*abs(z12)**2)",
        "parameters": {
            "c0_re": 1.0,
            "c0_im": 0.0,
            "c1": c1,
            "c2": c2,
        },
    }
# EVOLVE-BLOCK-END

import numpy as np

def _check():
    import importlib.util
    spec = importlib.util.spec_from_file_location("ip", "initial_program.py")
    ip = importlib.util.module_from_spec(spec); spec.loader.exec_module(ip)
    cand = ip.candidate_spec()
    expr, p = cand["expression"], cand["parameters"]
    # 1) interface check
    assert set(cand.keys()) == {"expression", "parameters"}
    # 2) variable/finiteness check on a deterministic grid
    g = np.linspace(-6, 6, 60)
    X1, Y1, X2, Y2 = np.meshgrid(g, g, g, g, indexing="ij")
    z1 = X1 - 1j * Y1; z2 = X2 - 1j * Y2
    z12 = z1 - z2
    ns = dict(exp=np.exp, abs=np.abs, np=np)
    ns.update({k: v for k, v in p.items()})  # c0? see note below
    # build c0 from re/im if needed
    ns["c0"] = p.get("c0", p.get("c0_re", 1.0) + 1j * p.get("c0_im", 0.0))
    ns.update({"z1": z1, "z2": z2, "z12": z12})
    F = eval(expr, {"__builtins__": {}}, ns)
    assert np.all(np.isfinite(F)), "non-finite values detected"
    # 3) analytic antisymmetry (swap electrons)
    ns2 = dict(ns); ns2["z1"], ns2["z2"] = z2, z1; ns2["z12"] = z2 - z1
    Fs = eval(expr, {"__builtins__": {}}, ns2)
    assert np.max(np.abs(Fs + F)) < 1e-8 * (np.max(np.abs(F)) + 1e-30), "antisymmetry broken"
    # 4) angular momentum M=3 (rotate by phi)
    phi = 0.37
    e = np.exp(-1j * phi)
    ns3 = dict(ns); ns3["z1"], ns3["z2"] = e * z1, e * z2; ns3["z12"] = e * z12
    Fr = eval(expr, {"__builtins__": {}}, ns3)
    assert np.max(np.abs(Fr - np.exp(-3j * phi) * F)) < 1e-8 * (np.max(np.abs(F)) + 1e-30), "M != 3"
    return True

print(_check())
