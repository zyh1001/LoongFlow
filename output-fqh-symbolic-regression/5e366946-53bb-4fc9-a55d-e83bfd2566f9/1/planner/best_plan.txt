## Phase 1: Mathematical Definition

Coordinates (mandatory convention): `z1 = x1 - i*y1`, `z2 = x2 - i*y2`, `z_rel = z1 - z2`, `r_rel^2 = |z1-z2|^2`, `Z_cm = (z1+z2)/2`. Identity `|z1|^2+|z2|^2 = 2|Z_cm|^2 + (1/2) r_rel^2` gives decoupled CM/relative widths.

**Chosen structure S\*:**
```
Psi(z1,z2;X) = c0 * (z1 - z2)**3
                 * (1 + p3 * |z1 - z2|**2)
                 * exp( -|p1|*(|z1|**2 + |z2|**2) - |p2|*|z1 - z2|**2 )
```
**Variables** `X = (c0_re, c0_im, p1, p2, p3)` — 5 fitted reals (c0 complex). `p1` init 0.25 (the Laughlin width 1/4), `p2` init 0, `p3` init 0.

**Constraints (hold for EVERY X; analytic identities):**
- C1 Exchange antisymmetry — `z_rel → -z_rel ⇒ Psi(r2,r1) = -Psi(r1,r2)`, all `|.|` factors invariant ⇒ exchange_error = 0.
- C2 Single M = 3 — under `z_i → e^{-iφ} z_i`, `Psi → e^{-3iφ} Psi`, no M-mixing ⇒ rotation_error ≈ 0.
- C3 Finiteness — exponent is `-|p1|·nonneg - |p2|·nonneg ≤ 0`, so `exp() ≤ 1` for any fitted p1,p2; polynomial prefactor exponentially suppressed at ∞. No poles.
- C4 ≤ 10 params (we use 5); closed form only, no I/O/branches.

**Objective** `f(X) = minimize L(X) = ||Psi_hat(.,X) − Psi_target||² / ||Psi_target||²` on validation (evaluator resolves the complex global scale), subject to C1–C4; tie-break toward fewer active parameters / lower complexity. The hidden TEST split is never touched.

2. **Multi-start initialization (mandated; N_restart ≥ 10):** with a FIXED seed (`numpy.random.default_rng(SEED)`), sample `p1~U(0.10,0.60)`, `p2~U(-0.20,0.20)`, `p3~U(-0.30,0.30)`, `c0=(1.0,0.0)` around the physical anchor.
3. **Continuous fit (delegated per restart):** `scipy.optimize.least_squares(..., method='trf', xtol=1e-12, ftol=1e-12, gtol=1e-12, max_nfev=2000)` (fallback `'lm'`); keep the lowest-validation-NMSE solution over all restarts.
4. **Greedy term pruning:** for each optional parameter (p2, then p3), set to 0, refit, and keep the pruned version iff validation fidelity does not worsen beyond ~1e-3 (implements the "prefer simpler" task rule).
