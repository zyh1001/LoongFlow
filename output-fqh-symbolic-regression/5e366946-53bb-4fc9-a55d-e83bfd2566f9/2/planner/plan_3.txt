PLAN 3 -- Grammar-Constrained Genetic Programming with Seeded Multi-Start
=========================================================================

MATHEMATICAL FORMULATION
------------------------
Variables: derivation trees G generated by a symmetry-constrained grammar
  whose ROOT is forced to the antisymmetric factor A = z12**odd (M=3),
  multiplied by a SYMMETRIC body B built from rotation invariants
  {|z1|^2+|z2|^2, |z12|^2, |Z_cm|^2, Z_cm*conj(Z_cm)} and a Gaussian
  envelope with primitives {+,-,*,exp,abs,**,integers 1..3, params p_k}.
Constraints:
  C1 antisymmetry, C2 M=3 (odd exponent at root).
  C3 finiteness (exponential args wrapped in -|p|).
  C4 <=10 fitted params; tree depth <= 4.
Objective:
  max  score(G) = (1 - validation_nmse(G)) * complexity_penalty(G)
  evaluated by the SAME evaluator used in the loop.

SOLVER STRATEGY
---------------
Standard evolutionary loop: population 40, tournament selection, subtree
crossover, point mutation, elitism 4; SIMULATED-ANNEALING acceptance on the
score; continuous parameters of each tree fitted by the evaluator's
scipy.optimize.least_squares.  SEEDED multi-start mandate: run N=5
independent populations with fixed seeds {0,1,2,3,4} and keep the best.

VALIDITY MECHANISM
------------------
Grammar projection: any non-antisymmetric or non-M=3 offspring is REJECTED
at birth (repair operator replaces the root with z12**3).  Post-hoc numeric
check for exchange/rotation/finiteness; fallback to the canonical
c0*z12**3*exp(-|p1|(|z1|^2+|z2|^2)) if a run yields nothing valid.

WHY THIS SOLUTION
-----------------
Advantages: open-ended structural discovery.  Disadvantages: high variance,
  slow (many evaluator calls), risk of complexity blow-up and hidden-test
  overfitting, and less reproducible.  The evidence already shows the
  correct structure is the M=3 Laughlin core, so brute-force structure
  search is unnecessary this iteration.  Least robust of the three.
